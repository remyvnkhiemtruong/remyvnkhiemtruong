## Engineering & research

### AI and RAG platform for local education

A research and software project titled **“Research and development of a system supporting the teaching and learning of Ca Mau Local Education using artificial intelligence and Retrieval-Augmented Generation (RAG)”**. The project was developed with **Trần Thị Thanh Trúc** under the guidance of **Lê Nguyễn Thế Bảo**.

The system consolidates and digitises local-education materials from the former Ca Mau and Bac Lieu provinces, then makes them accessible to students and teachers through a source-grounded AI website. Its controlled **agent-like RAG** pipeline evaluates retrieved context using three criteria: semantic relevance, suitability for the learner’s grade level, and source reliability. When the context does not meet the required confidence threshold, the system reformulates the query or changes its retrieval strategy before generating an answer.

In reported testing, the agent-like approach produced correct and complete answers in approximately **92%** of cases, compared with approximately **76%** for a conventional RAG baseline. The project won **First Prize** at the Mekong Delta STEM Education Day “Creative for the Community” and had previously won **Second Prize** at the 2025–2026 Ca Mau Provincial Science and Engineering Fair.

Planned development includes a larger standardised knowledge base, multi-source verification, mobile access, and adaptation of the platform for other provinces and cities.

**Core technologies:** artificial intelligence · LLMs · RAG · agent-like retrieval · vector search · source verification · educational web platform

### Electric-bicycle speed monitoring and accident warning

An embedded safety system designed for electric bicycles used by secondary and high-school students. The project combines an ESP32, GNSS positioning, motion analysis, wheel-speed measurement, 4G connectivity, Telegram alerts, and a Blynk dashboard.

The system monitors speed, detects overspeed events, evaluates possible crashes from motion and impact signals, and sends remote alerts with coordinates and a Google Maps link. The engineering work included sensor calibration, serial and I²C communication, cellular networking, event-detection logic, watchdog troubleshooting, and field testing.

**Core technologies:** ESP32 · NEO-M8N GNSS · MPU6050 IMU · A7680C 4G · TinyGPSPlus · Blynk · Telegram Bot API

### Smart agriculture and irrigation

An IoT system for monitoring field conditions and managing irrigation. It supports automatic and manual operation, soil and climate monitoring, remote visualisation, and configurable irrigation thresholds.

The project also explored data-driven irrigation, forecasting concepts, farmer-oriented usability, and communication alternatives for larger agricultural deployments.

**Core technologies:** ESP32 · environmental and soil sensing · Blynk · data visualisation · automated control

### Flood monitoring and machine-learning research

A research direction combining environmental sensing, time-series data, embedded monitoring, risk assessment, and machine-learning-assisted warning. The goal is to analyse patterns over time rather than treat every sensor reading as an isolated event.

### AI-assisted PDF-to-Word reconstruction

A Python desktop application concept for reconstructing editable Word documents from PDFs. The pipeline renders pages, performs AI/OCR analysis, interprets layout, reconstructs tables, recognises mathematical expressions, handles images, provides an editable preview, and exports structured `.docx` files.

The design includes batch processing, drag and drop, progress tracking, persistent settings, error logs, and support for formulas represented as LaTeX.

**Core technologies:** Python · PyQt5 · Gemini API · PyMuPDF · pdf2image · python-docx · OCR · LaTeX

### Large-scale document automation

Python utilities for repetitive document workflows, including batch Word-to-PDF conversion, content-based classification, scan/text PDF detection, file renaming, cleanup, resumable processing, multiprocessing, logging, and cloud-file synchronisation.

### Educational data lookup and visualisation

A web-based examination-result lookup system for more than 600 candidates, with candidate search, subject distributions, ranking tables, school-level analysis, priority-point summaries, and threshold-based result analysis.

**Core technologies:** HTML · CSS · JavaScript · Excel data processing · GitHub Pages · Cloudflare

### Raspberry Pi and edge AI

Experiments with Raspberry Pi 5, camera input, embedded Linux, and YOLO-based live traffic-sign recognition. Related work includes graphical interfaces, GPS and mobile-network integration, and edge deployment constraints.

## Инженерные и исследовательские проекты

### Платформа AI и RAG для краеведческого образования

Исследовательский и программный проект **«Исследование и разработка системы поддержки преподавания и изучения дисциплины “Местное образование провинции Камау” на основе искусственного интеллекта и Retrieval-Augmented Generation (RAG)»**. Проект создан совместно с **Trần Thị Thanh Trúc** под руководством **Lê Nguyễn Thế Bảo**.

Система объединяет и оцифровывает учебные материалы бывших провинций Камау и Бакльеу и предоставляет ученикам и учителям доступ к ним через AI-сайт с обязательной привязкой ответов к источникам. Управляемый конвейер **agent-like RAG** оценивает найденный контекст по трём критериям: семантическая релевантность, соответствие уровню обучения и надёжность источника. Если контекст не достигает установленного порога доверия, система переформулирует запрос или меняет стратегию поиска до генерации ответа.

По опубликованным результатам испытаний, agent-like подход дал правильные и полные ответы примерно в **92%** случаев против примерно **76%** у традиционной RAG-модели. Проект получил **Первую премию** Дня STEM-образования дельты Меконга «Творчество во благо общества», а до этого — **Вторую премию** провинциального конкурса научно-технических проектов Камау 2025–2026.

Дальнейшие планы включают расширение и стандартизацию базы знаний, проверку по нескольким источникам, мобильный доступ и адаптацию платформы для других провинций и городов.

**Основные технологии:** искусственный интеллект · LLM · RAG · agent-like retrieval · векторный поиск · проверка источников · образовательная веб-платформа

### Мониторинг скорости электровелосипеда и предупреждение об авариях

Встраиваемая система безопасности для электровелосипедов, которыми пользуются школьники. Проект объединяет ESP32, спутниковое позиционирование, анализ движения, измерение скорости колеса, связь 4G, уведомления Telegram и панель Blynk.

Система контролирует скорость, обнаруживает превышение, оценивает признаки возможного падения или столкновения и отправляет координаты со ссылкой Google Maps. Работа над проектом включала калибровку датчиков, интерфейсы UART и I²C, мобильную связь, логику обнаружения событий, устранение сбоев watchdog и полевые испытания.

**Основные технологии:** ESP32 · NEO-M8N GNSS · MPU6050 IMU · A7680C 4G · TinyGPSPlus · Blynk · Telegram Bot API

### Умное сельское хозяйство и орошение

IoT-система для контроля условий на участке и управления поливом. Поддерживает автоматический и ручной режимы, мониторинг почвы и окружающей среды, удалённую визуализацию и настраиваемые пороги полива.

В проекте также исследовались прогнозирование, управление на основе данных, удобство для фермеров и варианты связи для более крупных сельскохозяйственных систем.

**Основные технологии:** ESP32 · мониторинг почвы и среды · Blynk · визуализация данных · автоматическое управление

### Мониторинг наводнений и машинное обучение

Исследовательское направление, объединяющее экологические датчики, временные ряды, встраиваемый мониторинг, оценку риска и предупреждение с поддержкой машинного обучения. Цель — анализировать изменение показателей во времени, а не рассматривать каждое измерение отдельно.

### AI-реконструкция PDF в редактируемый Word

Концепция настольного приложения на Python для восстановления редактируемых документов Word из PDF. Конвейер включает рендеринг страниц, AI/OCR-анализ, интерпретацию макета, восстановление таблиц, распознавание формул, обработку изображений, редактируемый предпросмотр и экспорт структурированных `.docx`.

Предусмотрены пакетная обработка, drag-and-drop, индикация прогресса, сохранение настроек, журнал ошибок и представление формул в LaTeX.

**Основные технологии:** Python · PyQt5 · Gemini API · PyMuPDF · pdf2image · python-docx · OCR · LaTeX

### Массовая автоматизация документов

Инструменты на Python для пакетного преобразования Word в PDF, классификации по содержимому, определения сканированных и текстовых PDF, переименования и очистки файлов, возобновляемой обработки, multiprocessing, журналирования и синхронизации с облачными хранилищами.

### Поиск и визуализация образовательных данных

Веб-система поиска результатов экзаменов для более чем 600 кандидатов. Поддерживает поиск участника, распределения баллов, рейтинги, анализ по школам, статистику дополнительных баллов и анализ по порогу прохождения.

**Основные технологии:** HTML · CSS · JavaScript · обработка Excel · GitHub Pages · Cloudflare

### Raspberry Pi и Edge AI

Эксперименты с Raspberry Pi 5, камерой, embedded Linux и распознаванием дорожных знаков в реальном времени на основе YOLO. Связанные задачи включали графический интерфейс, интеграцию GPS и мобильной сети, а также ограничения периферийного развёртывания.

### Двуязычный офлайн-портал VVK STEM

Открытый offline-first портал со **120 интерактивными симуляциями STEM и математики** на вьетнамском и английском языках. Реализованы поиск, фильтры по предметам и классам, светлая, тёмная и проекторная темы, полноэкранный режим, избранное и история запусков. Портал работает с компьютера, USB-накопителя или школьной локальной сети без подключения к интернету.
